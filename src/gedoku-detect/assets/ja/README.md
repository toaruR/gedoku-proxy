# assets/ja/pref_city.tsv

日本語住所検出 (§7.10, `ja_dict::address`) の内蔵辞書。

## 出典

総務省「全国地方公共団体コード」(都道府県・市区町村の名称) に基づく行政区画名の
スナップショット。都道府県 (`kind=pref`) は47件全件を収録する。市区町村
(`kind=city`/`kind=ward`) は東京都特別区23区・政令指定都市20市とその行政区
(区)・および政令指定都市ではない道府県庁所在地を優先して収録した部分集合
(182件) であり、総務省データの全件 (町村を含む約1,900件) ではない。

同名の行政区 (例: 「中央区」は札幌市・さいたま市・千葉市等が共通で使用) は
本辞書のスキーマ (`name\tkind` の2列、所属市区町村を持たない) 上区別できない
ため、初出の1件のみを収録し重複行は含めない (`ja_dict::dict` の起動時
`JaDictError::DuplicateKey` fail_closed ロードと整合させるため)。

## スナップショット日付

2026-09-06 (本ファイル追加時点の知識に基づき作成。政令指定都市の行政区数は
2024年の浜松市行政区再編 (旧7区→中央区・浜名区・天竜区の3区) 後の値を採用)。

## 更新手順

1. 総務省の最新の「全国地方公共団体コード」または都道府県・市区町村の公式名称
   一覧を取得する。
2. 1行目ヘッダー `name\tkind` を維持したまま、`kind` を `pref`|`city`|`ward` の
   いずれかで追記する (町丁目以下は含めない。町丁目レベルは
   `ja_pii.address.extra_town_dict_path` で運用者が別途追加する想定、§7.10.2)。
3. 同名行 (複数市区町村にまたがる同名の区など) は初出のみ残し重複を排除する。
4. 本 README のスナップショット日付を更新する。
5. `cargo test -p gedoku-detect ja_dict::` を実行し、ローダーが再構築できることを
   確認する (再ビルドのみで反映され、ネットワークアクセスは不要)。
